### Give every character a mind of their own.

What they remember, what they never saw, who they love, what they hide.<br>
Your app keeps the chat, the model and the brains. Kiori stores no brains and no chats.

[![kiori.io](https://img.shields.io/badge/kiori.io-2b4acb?style=flat)](https://kiori.io)
[![Docs](https://img.shields.io/badge/docs-2b4acb?style=flat)](https://kiori.io/docs)
[![help@kiori.io](https://img.shields.io/badge/help%40kiori.io-2b4acb?style=flat)](mailto:help@kiori.io)

</div>

- 🧠 **Three calls.** `create` a brain from a character card, `organize` it as the chat moves, and `recall` what the character knows right before they speak.
- 🤫 **Secrets stay put.** Each mind knows only what it saw, heard or was told. A whisper stays with the people in the room.
- 🔒 **Nothing kept.** The brain is a JSON object that travels with each call and lives wherever you keep it.
- 🧩 **Fits in.** JavaScript and Python SDKs, an OpenAI-compatible drop-in, and a SillyTavern extension. Any model, any language.

In private beta, free while it lasts: [ask for access](https://kiori.io/#access). The code is in [kiori-ai/kiori](https://github.com/kiori-ai/kiori): the server is source-available (PolyForm Noncommercial), the SDKs and the [SillyTavern extension](https://github.com/kiori-ai/SillyTavern-Kiori) are MIT.
